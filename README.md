# MathInterpreter

[![C++](https://img.shields.io/badge/C%2B%2B-20-blue)]()

Консольный интерпретатор математических выражений, написанный на C++ с использованием методологии разработки через тестирование (TDD) в учебных целях.

## Описание

Этот проект реализует парсер и вычислитель математических выражений, поддерживающий базовые арифметические операции и скобки. Основная цель — не столько создать готовый продукт, сколько отработать навыки:
- Разработки через тестирование (Test-Driven Development)
- Построения лексера и парсера
- Работы с `CMake` и системами автоматической сборки
- Написания чистого, расширяемого кода на C++

## Возможности

Проект еще в разработке и не все возможности еще реализованы

- Поддержка базовых операторов: +, -, *, /
- Унарный плюс и минус
- Приоритет операций 
- Учет скобок
- Создание собственных констант с помощью оператора присваивания (=). 
- Встроенные константы (pi, e). 
- Встроенные функции с переменным числом аргументов.
- Задание новых функций.

## TDD в проекте

Для разработки использовался свой тестовый фреймворк.
Разработка велась строго по циклу **Red → Green → Refactor**:

- Сначала писался падающий тест на новую функциональность (`RED`)
- Затем минимальный код, чтобы тест прошёл (`GREEN`)
- Далее проводился рефакторинг с сохранением зелёной полосы (`REFACTOR`)

Каждый коммит по возможности соответствовал одному такому циклу. Тестами покрыты:
- Простые числа и операторы
- Составные выражения со скобками
- Ошибочные входные данные
- [Граничные случаи и т.д.]

## Сборка и запуск

### Требования
- Компилятор с поддержкой C++20 (GCC, Clang, MSVC)
- CMake >= 3.23
- Собственный Фреймворк для тестирования
